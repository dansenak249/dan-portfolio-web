How the number is calculated
In code
t = clamp( (Dmax − d) / (Dmax − Dmin), 0, 1 ) ← urgency, 0 to 1 rate = Math.pow(t, k) * Rmax ← surcharge rate total = base * (1 + rate) ← what the client pays
In math
t(d) = {
0 d ≥ Dmax
Dmax − d Dmax − Dmin Dmin < d < Dmax
1 d ≤ Dmin
r(d) = Rmax · t(d)k
P(d) = P0 · ( 1 + r(d) )

t is a piecewise function of the deadline, clamped to the closed interval [0, 1]. P0 is the base price and P(d) is the quoted total. Rounding is applied to r(d) after the exponent, so it does not change either endpoint.

  • d ≥ Dmaxt clamps to 0, so the price stays at base. No upper limit — 60 days costs the same as 28.
  • d = Dmint is exactly 1, so the surcharge lands on Rmax whatever k is set to.
  • d < DminOut of range. The tool marks it as not accepted instead of quoting a number.
  • k = 1Straight line. Halfway between the anchors costs half the max surcharge.
  • k < 1Climbs fast early, then flattens. Charges more for mid-range deadlines.
  • k > 1Stays gentle in the middle, then steepens near Dmin. Easier on mid-range jobs.
